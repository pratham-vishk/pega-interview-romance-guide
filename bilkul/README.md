# Bilkul — Google SWE Interview Operating System

**7-Day Pattern Mastery + LLD + HLD + Interview Simulation**

An interactive interview-training system for Google SWE L4 (L5 stretch) — built for Java backend engineers who want pattern recognition, not 300 blind LeetCode solves.

## Quick Start

```bash
cd bilkul
python3 generate_os.py
```

Open `google-swe-interview-os.html` in your browser for full interactivity (checkboxes, XP tracking, quizzes, mock interviews).

PDF export: `Google_SWE_Interview_OS.pdf` (generated via WeasyPrint).

## What's Inside

| Module | Content |
|--------|---------|
| **64 DSA Patterns** | Full Pattern Cards: intuition, triggers, Java templates, complexity, traps |
| **Recognition Engine** | Decision tree + 30-second diagnosis framework |
| **Java Templates** | HashMap, Heap, BFS, DFS, UF, Dijkstra, Trie, DP, Backtracking |
| **LLD** | SOLID, 11 design patterns, 10 LLD problems with Java skeletons |
| **HLD** | 28 concepts, architecture building blocks, 15 system designs |
| **Resume Deep Dive** | Questions from your Dell/Kafka/load balancing/LLM experience |
| **7-Day Plan** | 8–10 hrs/day intensive first pass |
| **Next 83 Days** | Spaced repetition + mocks + depth |
| **Interview Simulation** | DSA + System Design mock mode with hints |
| **Gamification** | XP, levels, boss battles, weakness tracker |
| **10 Cheat Sheets** | Printable 1-pagers |

## Philosophy

> Do NOT optimize for reading. Optimize for **active learning, recall, recognition, practice, and interview performance.**

After 7 days you should have the **complete mental map**. After 90 days — interview ready.
